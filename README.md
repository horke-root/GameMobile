# Розробка мобільної гри

«Moto Race: Demo» — це мобільна 2D-гра у жанрі фізичного сайдскроллера з елементами економіки та тюнінгу. Проект розроблений на базі ігрового рушія **Unity** з використанням мови програмування **C#** та орієнтований на мобільні платформи під керуванням операційної системи Android.

Ігровий процес поєднує в собі гаражну романтику покращення мопеда та заїзди пересіченою місцевістю з виконанням трюків та збором монет.

---

Завантижити гру: https://github.com/horke-root/GameMobile/releases/tag/Demo

## 🎮 Основні Ігрові Механіки

1. **Фізична модель руху (2D Physics)**
   * Рух мопеда базується на фізичному рушії Unity (`Rigidbody2D`, `WheelJoint2D`).
   * Розраховується реалістична поведінка двоколісного транспорту: крутний момент двигуна, передавальні числа трансмісії, аеродинамічний опір та опір коченню коліс.

2. **Гараж та система покращень (Upgrade System)**
   * Гравець може покращувати два ключові вузли мопеда:
     * **Двигун (Engine):** Підвищує максимальну потужність двигуна (`maxHP`).
     * **Зірки трансмісії (Primary Drive):** Коригує загальне передавальне число для оптимізації балансу між швидкістю розгону та максимальною швидкістю.
   * Вартість покупки покращень динамічно розраховується за формулою:
     $$\text{Cost} = 2 \cdot \text{Level}^2 + 16 \cdot \text{Level} + 32$$

3. **Система трюків та асистент балансування (Wheelie Assist)**
   * Під час заїзду гравець може утримувати кнопку **Stunt** для підняття мопеда на заднє колесо (їзди в стилі *wheelie*).
   * Інтегрований фізичний асистент (`Wheelie Assist`) аналізує кут нахилу рами та автоматично дозує кутовий момент, допомагаючи утримувати рівновагу на куті близько 45° та запобігаючи миттєвому падінню водія на спину.

4. **Термодинаміка двигуна (Engine Temperature)**
   * Робота двигуна на високих обертах (`RPM`) призводить до його нагрівання.
   * Гравець повинен контролювати температуру за допомогою термометра на екрані.
   * Перевищення критичного порогу в **120°C** викликає перегрів двигуна, через що мопед глохне, а заїзд завершується аварійно.
   * Двигун охолоджується під час руху накатом (коли ручка газу відпущена) або при перетині чекпоінтів.

5. **Локальне збереження прогресу (PlayerPrefs)**
   * Дані про баланс монет та рівні покращень автоматично зберігаються в реєстрі пристрою (або локальних налаштуваннях додатка) за допомогою вбудованого механізму Unity `PlayerPrefs` під ключами "Coins", "EngineLevel" та "PrimaryDriveLevel".
   * Збереження відбувається безпосередньо при покупці покращень у гаражі, перетині чекпоінтів та закінченні заїзду.

## 🛠 Технологічний Стек

* **Ігровий рушій:** Unity (версія 2021.3+ LTS)
* **Мова програмування:** C#
* **Інтерфейс користувача:** Unity UI (uGUI) з використанням TextMesh Pro для чіткого відображення шрифтів.
* **Збереження даних:** вбудоване сховище `PlayerPrefs` (запис у реєстр/локальний конфіг).
* **Анімація та ефекти:** Частинки Unity (`Particle System`) для імітації іскор та диму з-під коліс.

## 📂 Структура Проекту та Основні Класи

Код проекту розділений на логічні модулі:
* 📑 **`BikeController.cs`** — серце фізичної моделі. Обробляє ввід користувача, обчислює поточні оберти двигуна (`RPM`), автоматично перемикає передачі трансмісії (АКПП), крутний момент на колесах, аеродинамічний опір та термодинамічну модель нагріву.
* 📑 **`UpgradeUI.cs`** — керує візуальним відображенням рівнів деталей та поточного балансу в гаражі, розраховує вартість покращень за формулою та блокує кнопки при нестачі коштів.
* 📑 **`RaceService.cs`** — керує логікою заїзду, нарахуванням монет після перетину фінішу або аварії, а також збереженням балансу в PlayerPrefs.
* 📑 **`MobileButton.cs`** — універсальний скрипт для сенсорного керування кнопками на екранах мобільних пристроїв.

## 🚀 Встановлення та Запуск

### Запуск у Unity Editor:
1. Завантажте або клонуйте репозиторій з проектом.
2. Відкрийте проект через **Unity Hub** (рекомендовано використовувати версію Unity 2021.3 LTS або новішу).
3. Перейдіть до папки `Assets/_Project/Scenes/` та відкрийте стартову сцену `Login 1`.
4. Натисніть кнопку **Play** у верхній панелі Unity Editor.
5. Для керування з клавіатури в режимі емуляції використовуйте:
   * **W / Стрілка вгору** — Газ (акселератор).
   * **S / Стрілка вниз** — Заднє гальмо.
   * **A / Стрілка вліво** — Переднє гальмо.
   * **Space (Пробіл)** — Кнопка трюку (Stunt / Wheelie).

### Встановлення на Android-пристрій:
1. Скомпілюйте проект в Unity через меню `File -> Build Settings -> Android -> Build`.
2. Перенесіть згенерований виконуваний файл `.apk` на пристрій.
3. У налаштуваннях безпеки смартфона дозвольте встановлення додатків з невідомих джерел.
4. Встановіть та запустіть гру.
